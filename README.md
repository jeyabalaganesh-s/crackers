# Crackers Company – Online Order Submission System

A modern, responsive web application built with **React, TypeScript, and Vite** that allows customers to browse crackers products, submit online order requests, and share their contact details easily.

## 🚀 Tech Stack

- **React** – Frontend UI development
- **TypeScript** – Type-safe development
- **Vite** – Fast development server and build tool
- **Tailwind CSS** – Responsive UI styling
- **React Router** – Client-side navigation
- **Lucide React** – Icons

## ✨ Features

- Responsive and user-friendly interface
- Crackers product catalogue
- Product categories and details
- Online order submission form
- Customer information collection
- Product quantity selection
- Order summary
- Form validation
- Submission confirmation

## 🛠️ Getting Started

### Prerequisites

- Node.js (v20 or later recommended)
- npm

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd crackers-website
```

Install dependencies:

```bash
npm install
```

### Development Server

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 📋 Available Scripts
